Extracting your files

  1. Mac or Linux: open Terminal, go to the folder with the download, and run tar -xvf <file>.tar.gz.
  2. Windows: install 7-Zip, right-click the file and choose 7-Zip > Extract Here. Repeat on the extracted .tar file.
  3. Older archives are .zip files, which open directly on Mac and Windows.
